## 문서별 내용

### 빠른 시작

설치부터 첫 업무 추가, 저장 위치 확인까지 설명합니다.

### 사용 가이드

업무 추가/수정/삭제, 상태 변경, 과거 문서 조회, 일일보고 작성 방법을 설명합니다.

### 설정 가이드

테마, 인사말, 꼬리말, 날짜 토큰, 업무 영역 제목, `settings.json`을 설명합니다.

### 빌드/배포

PyInstaller 빌드, GitHub Actions, Release 실행파일 배포 방법을 설명합니다.
