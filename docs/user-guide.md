# 사용 가이드

## 업무 추가

`오늘 해야 할 일` 탭에서 내용을 작성한 뒤 `+ 업무 추가`를 누릅니다.

추가와 동시에 Markdown 파일에 저장됩니다.

## 업무 수정

목록에서 기존 업무를 선택합니다.

내용을 수정하면 `변경사항 저장` 버튼이 나타납니다.

## 업무 삭제

기존 업무를 선택한 뒤 `삭제`를 누릅니다.

확인 후 현재 날짜의 Markdown 파일에서도 삭제됩니다.

## 상태

업무 상태는 세 가지입니다.

- 예정
- 진행중
- 완료

다음날 문서 생성 시 완료된 업무만 이전 업무 영역으로 이동합니다.

## 링크

링크는 이름과 URL을 따로 입력합니다.

예:

```text
링크 이름: 1694
URL: http://naver.com
```

저장 결과:

```markdown
- 관련 문서: [1694](http://naver.com)
```

URL만 입력하면 URL 자체가 링크 이름으로 사용됩니다.

## 과거 문서

왼쪽에서 연도와 월을 선택하면 해당 월의 문서를 확인할 수 있습니다.

날짜를 선택하면 과거 문서를 열고 수정할 수 있습니다.

## Markdown 파일 위치

```text
reports/YYYY/MM/YYMMDD.md
```

예:

```text
reports/2026/09/260923.md
```

## 일일보고

`일일보고 작성`에서 날짜, 인사말, 꼬리말을 확인한 뒤 보고서를 생성합니다.

기본 분류:

- 진행 업무: 진행중 + 완료
- 예정 업무: 예정

필요하면 생성 전에 인사말과 꼬리말을 임시로 수정할 수 있습니다.
