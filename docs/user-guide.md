# 사용 가이드

## 업무 추가

`오늘 업무` 영역에서 내용을 작성한 뒤 `+ 업무 추가`를 누릅니다.

추가와 동시에 Markdown 파일에 저장됩니다.

## 업무 수정

목록에서 기존 업무를 선택합니다.

내용을 수정하면 `변경사항 저장` 버튼이 나타납니다.

## 업무 삭제

기존 업무를 선택한 뒤 `삭제`를 누릅니다.

확인 후 현재 날짜의 Markdown 파일에서도 삭제됩니다.

## 상태

업무 상태는 세 가지입니다.

- 예정
- 진행중
- 완료

다음날 문서를 만들 때 `진행중`과 `예정` 업무만 오늘 업무로 이월됩니다. `완료` 업무는 이월하지 않습니다.

## 이전 업무 호환

현재 앱에서는 별도의 `이전 업무` 입력 영역을 사용하지 않습니다.

이전 버전에서 저장된 이전 업무 데이터는 기존 Markdown 보존을 위해 유지되지만 일일보고 생성에는 사용하지 않습니다.

## 링크

링크는 이름과 URL을 따로 입력합니다.

예:

```text
링크 이름: 1694
URL: http://naver.com
```

저장 결과:

```markdown
- 관련 문서: [1694](http://naver.com)
```

URL만 입력하면 URL 자체가 링크 이름으로 사용됩니다.

## 전체 검색

좌측의 `전체 검색`에 단어나 문구를 입력하면 `reports/` 아래의 모든 일일 문서를 검색합니다.

검색 대상은 업무 제목, 링크 이름, URL, 주요 내용, 상태입니다. 직접 수정한 Markdown의 일반 텍스트와 이전 버전의 이전 업무 데이터도 검색됩니다.

결과에는 날짜, 업무 상태, 업무 제목, 일치한 내용이 표시됩니다.

현재 업무 결과를 클릭하면 해당 날짜를 열고 일치한 업무를 선택합니다. 이전 버전 데이터나 일반 Markdown 결과는 해당 날짜 문서를 엽니다.

검색어를 지우면 기존 연도/월/날짜 탐색으로 돌아갑니다.

## 과거 문서

왼쪽에서 연도와 월을 선택하면 해당 월의 문서를 확인할 수 있습니다.

날짜를 선택하면 과거 문서를 열고 수정할 수 있습니다.

## Markdown 파일 위치

```text
reports/YYYY/MM/YYMMDD.md
```

예:

```text
reports/2026/09/260923.md
```

## 일일보고

`일일보고 작성`에서 날짜, 상단 문구, 꼬리말을 확인한 뒤 보고서를 생성합니다.

기본 분류:

- 진행 업무: 진행중 + 완료
- 예정 업무: 진행중 + 예정

필요하면 생성 전에 상단 문구와 꼬리말을 임시로 수정할 수 있습니다.

상단 문구 다음에 바로 `[진행 업무]`가 이어집니다. 날짜 제목도 상단 문구의 날짜 토큰으로 직접 구성할 수 있습니다.
